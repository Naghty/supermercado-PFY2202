# Supermercado - Benjamin Zamorano - PFY2202

Sitio de gestion de inventario de un supermercado hecho con React, React Router y Tailwind CSS.

## Funcionalidades

- Agregar articulos al inventario (formulario con estado global)
- Lista de articulos en tabla con filtro por categoria
- Detalle de articulo con boton para agregar al carrito
- Carrito de compras con aumento y disminucion de cantidades
- El inventario se actualiza al agregar, quitar o modificar cantidades del carrito

## Ejecucion

```
npm install
npm run dev
```
